Mark II v@VERSION@ - Linux x64 (versao nativa GPUI)

1. Extraia a pasta e rode:  ./markii
   Para ter o atalho no menu: copie markii.desktop para ~/.local/share/applications/
   e ajuste o caminho em Exec= e Icon= para esta pasta.

2. Precisa de placa de video com Vulkan (driver Mesa ou NVIDIA) e X11 ou Wayland.
   Ubuntu/Debian: sudo apt install libvulkan1 mesa-vulkan-drivers libxkbcommon-x11-0

3. Sensores: no Linux o Mark II le os sensores direto do kernel (hwmon), sem
   driver extra e sem administrador.
   - Ventoinhas e placa-mae: se nao aparecerem, o modulo do chip da placa nao
     esta carregado. Rode "sudo sensors-detect" (pacote lm-sensors) ou, por
     exemplo, "sudo modprobe nct6775" / "sudo modprobe it87".
   - Potencia da CPU (RAPL) e a marca/slot de cada pente de RAM (dmidecode) so
     aparecem rodando como root:  sudo ./markii
   - GPU NVIDIA: usa o driver proprietario (NVML). GPU AMD: amdgpu.

4. RGB (botao "RGB" no topo): usa o OpenRGB que vem nesta pasta
   (OpenRGB.AppImage, GPL-2.0) para memoria, placa de video, placa-mae,
   ventoinhas e coolers. Uma vez so, para liberar o acesso ao hardware:
     sudo ./OpenRGB.AppImage --generate-udev-rules /etc/udev/rules.d/60-openrgb.rules
     sudo udevadm control --reload-rules && sudo udevadm trigger
   Memoria e placa de video (SMBus): sudo modprobe i2c-dev  e, conforme a CPU,
     sudo modprobe i2c-i801  (Intel)  ou  sudo modprobe i2c-piix4  (AMD)
   AppImage precisa de FUSE 2 (Ubuntu 22.04+: sudo apt install libfuse2).
   "Reaplicar ao ligar o PC" cria ~/.config/autostart/markii-rgb.desktop.

Configuracoes: ~/.config/com.akaineko.markii/config.json
No Linux nao ha icone na bandeja: fechar a janela encerra o app.

Logos de marcas: Simple Icons (CC0, veja licencas/). As marcas pertencem aos
seus donos e so identificam o hardware.
